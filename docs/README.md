# docs

User documentation for OrielOS.

These pages are also published as the repository's [wiki](https://github.com/ncjsvr/OrielOS/wiki), which is generated from this folder.

Contains:

- [Using Start](start-menu.md): searching, pinning apps, All apps, recommendations, and the account and power buttons.
- [Try OrielOS in a virtual machine](install-vm.md): build OrielOS, make a virtual machine disk and start it in QEMU or VMware Workstation.
- [Updates and going back](updates.md): how OrielOS prepares an update for the next restart, and how to go back to the previous version.
- [Installing apps](apps.md): the Store, Flathub, and how Firefox arrives on first boot.
- [Keyboard shortcuts](keyboard-shortcuts.md): the Windows shortcuts for Start, Files, Run, Process Manager, Screenshot and more.
- [Secure Boot and your drivers](secure-boot.md): the one-time blue screen that lets the NVIDIA driver and other drivers load, and the firmware update warning.
- [Games and controllers](games-and-controllers.md): what OrielOS sets up for games, pairing Xbox and PlayStation controllers, and apps for gaming mice and lighting.
- [Games with anti-cheat](anti-cheat.md): why OrielOS always starts in the mode that games with anti-cheat need, and why there's Sleep but no Hibernate.

Will contain:

- Guides for installing.
- Guides for running Windows programs and for each game's settings.

Need help? Ask in the [Q&A](https://github.com/ncjsvr/OrielOS/discussions/categories/q-a) category of GitHub Discussions, or chat on [the official OrielOS Discord server](https://discord.gg/RnpZYaKbHA).
