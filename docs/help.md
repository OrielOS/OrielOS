# Getting help

Stuck, or found something that doesn't work? Here's where to look and who to ask.

## Look it up

- **[Status](status.md)** lists what works today, what doesn't work yet and what's planned.
- **[Known limitations](known-limitations.md)** explains what OrielOS can't do yet and what it won't do by design, such as Hibernate or games whose publishers block Linux.
- **The other guides** cover installing, the desktop, apps, games and updates. On [orielos.org/guides](https://orielos.org/guides/), "Find a topic" lists every topic from A to Z.

## Ask a question

- **[GitHub Discussions](https://github.com/ncjsvr/OrielOS/discussions/categories/q-a):** ask in the Q&A category. Answers stay there for the next person with the same question.
- **[The official OrielOS Discord server](https://discord.gg/RnpZYaKbHA):** chat live and get quick help. It's the only official one: any other server using the name isn't run by the project.

## Report a problem

If something is broken, open an issue on [GitHub](https://github.com/ncjsvr/OrielOS/issues/new/choose). It helps to include:

- **Your OrielOS version**, from **Settings > Update**, or **Settings > System > About**.
- **Your PC:** its graphics card, and whether it's a desktop or a laptop.
- **What you did, what you expected and what happened instead**, with a photo or screenshot of any error.

Security problems are different: please don't post them in public. The [security policy](https://github.com/ncjsvr/OrielOS/blob/main/SECURITY.md) says how to report one privately.

## If OrielOS won't start properly

- **After an update:** OrielOS goes back to the previous version by itself if a new one fails to start twice. You can also go back yourself from Settings or from the boot menu: see [Updates and going back](updates.md).
- **The graphics driver doesn't load,** and the screen looks low-resolution or games can't find the graphics card: finish the one-time step in [Secure Boot and your drivers](secure-boot.md).
