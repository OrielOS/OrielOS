# Keyboard shortcuts

OrielOS uses the Windows keyboard shortcuts you already know. The Windows key is the one with the Windows logo; on other keyboards it may be called Super or Command.

| Shortcut | What it does |
|---|---|
| Windows key | Opens Start |
| Windows + E | Opens Files |
| Windows + S | Opens Start ready to search, with your recent searches and most used apps |
| Windows + R | Opens Run, to start an app or open a file, folder or website by typing its name. The last one you ran is ready to run again, and the list holds the ones before. Windows names such as `cmd`, `explorer`, `control` and `taskmgr` open Terminal, Files, Settings and Process Manager |
| Windows + L | Locks the screen |
| Alt + F4 | Closes the window you're using. On the desktop, asks what the computer should do: switch user, sign out, sleep, shut down or restart |
| Ctrl + Alt + Del | Shows Lock, Switch user, Sign out, Change a password and Process Manager, with the power button at the bottom right |
| Windows + D | Shows the desktop; press it again to bring the windows back |
| Windows + Tab | Shows all your open windows and desktops |
| Alt + Tab | Switches between open windows |
| Ctrl + Alt + Tab | Shows the open windows and keeps them on screen after you let go: choose one with the arrow keys and Enter, or click it |
| Windows + I | Opens Settings |
| Windows + P | Chooses how your screens are used: PC screen only, Duplicate, Extend or Second screen only. Press P again (holding Windows) to move down the list, then Enter |
| Windows + Pause | Opens Settings at About, with this PC's specifications and OrielOS's version |
| Windows + U | Opens Settings at Accessibility |
| Left Alt + Left Shift + Print Screen | Turns a high-contrast colour scheme on, or back off |
| Left Alt + Left Shift + Num Lock | Turns Mouse Keys on or off: the number pad moves the pointer, and 5 clicks |
| Windows + N | Opens your notifications and the calendar |
| Ctrl + Esc | Opens Start, like the Windows key |
| Windows + X | Opens the quick links menu above Start: Installed apps, Power options, System, Device Manager, Network connections, Terminal, Process Manager, Settings, Files, Search, Run, Shut down or sign out, and Desktop. Press the underlined letter to choose one; right-clicking Start opens it too |
| Windows + Shift + S | Screenshot: drag to choose part of the screen to capture |
| Windows + V | Clipboard history: everything you copied recently |
| Windows + . | Emoji picker |
| Ctrl + Shift + Esc | Opens Process Manager, to see what's running and end a program that has stopped responding |
| Windows + Left or Right arrow | Snaps the window to the left or right half of the screen |
| Windows + Z | Snap layouts: choose where the window goes, such as a half, a third or a quarter of the screen |
| Windows + Up arrow | Maximises the window; a window snapped to a half goes to that half's top quarter |
| Windows + Down arrow | Restores a maximised window and minimises any other; a window snapped to a half goes to its bottom quarter |
| Windows + Shift + Up arrow | Stretches the window to the full height of the screen |
| Windows + Shift + Left or Right arrow | Moves the window to the next screen in that direction |
| Windows + M | Minimises every window; Windows + Shift + M brings them back |
| Windows + Home | Minimises every window but the one you're using; press it again to bring them back |
| Alt + Esc | Sends the window to the back and switches to the next one |
| Alt + Space | Opens the window's menu: Restore, Move, Size, Minimise, Maximise and Close. Clicking the app's icon at the top left of a window opens it too; double-clicking the icon closes the window |
| Windows + Ctrl + D | Adds a desktop and switches to it; its name shows for a moment |
| Windows + Ctrl + Left or Right arrow | Switches to the desktop on that side |
| Windows + Ctrl + F4 | Closes the desktop you're on; its windows move to the one beside it |
| Windows + Alt + D | Opens the calendar, like clicking the clock |
| Windows + Alt + B | Turns HDR on or off on screens that can show it |
| Windows + Space | Switches to the next keyboard layout |
| Windows + Ctrl + Enter | Turns the screen reader on or off |
| Windows + Plus or Minus | Zooms the screen in or out (Windows + 0 goes back) |
| Shift five times | Asks whether to turn on Sticky Keys; holding Shift for eight seconds asks about slow keys |
| Windows + A | Opens Quick Settings |
| Windows + B | Opens the hidden icons in the system tray |
| Windows + 1 to 9 | Opens, or switches to, the app in that place on the taskbar |
| Windows + PrtSc | Saves a screenshot of the whole screen to Pictures/Screenshots |
| Alt + PrtSc | Captures the active window |

Settings is OrielOS's Settings app (see [Settings](settings.md)). Process Manager, Screenshot, Files and Clipboard history are listed under those names in Start, and Start search also finds them by words such as "processes", "end task", "snip", "print screen" and "paste". Clipboard history in Start does the same as Windows + V.

## Snap layouts

Press Windows + Z, or rest the pointer on a window's maximise button, to see six layouts for the window you're using: two halves, two thirds beside one third, three thirds, a half beside two quarters, four quarters, and a half between two quarters. Click an area to move the window there. With the keyboard, the arrow keys move to the next area in that direction (Up and Down between the top and bottom quarters), Tab steps through every area, and Enter or Space snaps the window. Each layout also shows a number: press it, then the number that appears in the area you want. Escape closes the layouts without changing anything.

## Changing a shortcut

Open Settings, then **Keyboard** > **Shortcuts**. Find the app or action, select the shortcut and press the new keys. Your changes apply only to your account.
