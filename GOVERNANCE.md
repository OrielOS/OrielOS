# Governance

OrielOS has one maintainer, GitHub user `ncjsvr`. The maintainer makes the final decisions, reviews every pull request and merges it.

Decisions are made in public, in issues, pull requests and GitHub Discussions, so anyone can follow the reasoning and take part. Disagreement is welcome when it is respectful and gives reasons; the maintainer weighs it and decides.

This model may change as the project grows. If it does, this document will be updated first.
