Before you install

A few things OrielOS can’t do, so they aren’t a surprise. Some games won’t run, because their anti-cheat doesn’t allow Linux. There’s no Hibernate; sleep works. Microsoft 365 and Adobe apps aren’t included and don’t run; their websites do, and the Store has Linux alternatives. Status lists what works today, and known limitations lists the rest. More answers are on the FAQ.

Check your download

Before you write the installer to a USB stick, check that it arrived complete and unchanged: work out its SHA-256 checksum on your own computer and compare it with the one shown abovethe line for OrielOS.iso in SHA256SUMS on the release’s page. The result must match exactly. If it doesn’t, download the installer again.

On Windows

Open PowerShell in the folder you downloaded it to and run:

Get-FileHash .\OrielOS.iso

On macOS

Open Terminal in the download folder and run:

shasum -a 256 OrielOS.iso

On Linux

In a terminal in the download folder, run:

sha256sum OrielOS.iso

Or download SHA256SUMS into the same folder and let it compare for you. It prints “OK” when the checksum matches:

sha256sum -c SHA256SUMS --ignore-missing

Write it to a USB stick

Write the installer to a USB stick with a tool such as Fedora Media Writer, balenaEtcher or Rufus, start your PC from the stick and follow the installer’s steps. Install OrielOS takes you through each one, including how to keep Windows next to OrielOS.
