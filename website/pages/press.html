In one sentence

OrielOS is a free, open-source Linux desktop for gaming and development.

In a paragraph

OrielOS is a free, open-source Linux desktop for PCs with NVIDIA RTX graphics, for gaming and development. It’s built on Fedora’s image-based system and the KDE Plasma desktop, with a centred taskbar, a Start menu with search, one Settings app and the keyboard shortcuts people know from Windows. Installing apps, updating, changing settings and running games all work without typing a command. The whole system updates as one signed image in the background, and if an update gives you trouble you can go back to the previous version from Settings. OrielOS collects nothing about you or your PC.
