--- title: OrielOS FAQ: download, hardware and games heading: FAQ description: Answers before you install OrielOS: how it differs from Bazzite, the hardware it needs, .exe files, anti-cheat, rollback, telemetry and keeping Windows. ---

Short answers before you install. The guides go into more detail, and the download page has the installer.

How is OrielOS different from Bazzite?

Both are Fedora Atomic desktops: the system is one image, and an update replaces that image instead of changing it piece by piece. OrielOS is its own desktop on that base. It uses KDE Plasma with OrielOS’s taskbar and Start menu, and Steam from the Store. In testing builds, Windows games use Proton with GE-Proton as the default, and .exe and .msi files open through Run this app; both reach the stable version with its next release. Updates download in the background, and you can go back to the previous version from Settings. OrielOS collects no telemetry. It’s early, and it targets desktop PCs with NVIDIA RTX graphics, 20-series or newer.

Can I download it?

Yes. The current stable release is {{release.version}}, and it has an installer.An installer will be published with the first stable release. Get the ISO from the download page, check its SHA-256, and write it to a USB stick of at least 2 GB. The installer downloads OrielOS, so the PC needs an internet connection. The install guide goes through each step.

What hardware does it need?

A desktop PC with NVIDIA RTX graphics, 20-series or newer, a 64-bit Intel or AMD processor, and UEFI with Secure Boot. It needs at least 60 GB free, as a whole drive or unused space next to Windows, a USB stick of 2 GB or more, and internet during the install. PCs with only AMD or Intel graphics aren’t supported yet. So far it has been checked on a laptop with an NVIDIA GeForce RTX 4050 Laptop GPU; laptops aren’t what it’s built for. Status lists every PC checked, and Install OrielOS has the full requirements.

Does it run .exe/.msi files?

Yes, in testing builds, through Run this app. It reaches the stable version with its next release. Double-click a .exe or .msi file and OrielOS shows the file and where it came from, then asks before doing anything. It runs the program through GE-Proton, in a Windows set-up of its own, and shortcuts its installer creates can appear in Start. It’s new and has only been tried with a few programs. Programs that need special drivers don’t run, and Microsoft 365 and Adobe apps don’t run. A Linux version from the Store is a better choice when there is one. See Windows programs.

Will my anti-cheat games work?

Often not. The publisher decides whether a game’s anti-cheat allows Linux. If it doesn’t, the game won’t start on OrielOS or on any other Linux system. Valorant, League of Legends, Call of Duty and Battlefield 6 are examples. OrielOS does start in the way Easy Anti-Cheat’s Linux support asks for, so a game that allows Linux can run. There’s no Hibernate, because that start rules it out; sleep works. Known limitations and games with anti-cheat say more.

Can I undo a bad update?

Yes. OrielOS keeps the previous version for 14 days. In Settings, open Update and choose “Go back to the previous version…”. If a new version fails to reach the desktop twice, the next start uses the previous one by itself. A version you went back from isn’t offered again. The updates guide explains it.

Does it collect data?

No. OrielOS collects nothing about you or your PC, and it doesn’t send Fedora’s anonymous weekly package count. This website sets no cookies and runs no trackers.

Can I keep Windows?

Yes. Free at least 60 GB in Windows’ Disk Management and leave that space unallocated. The installer uses it and leaves Windows in the boot menu, which shows for five seconds at each start. If the drive is encrypted, save the recovery key first, because Windows may ask for it afterwards, and turn off Fast Startup. Back up anything you can’t lose. The install guide shows each step.
