Welcome to OrielOS

A Linux desktop for gaming and development

OrielOS is a free, open-source Linux desktop for PCs with NVIDIA RTX graphics. Steam and Proton come with it, you can roll an update back, and it collects nothing about you.

Why OrielOS

  • Familiar from the first boot

    A centred taskbar, a Start menu with search and pinned apps, a Settings app organised by task, and the keyboard shortcuts you know from Windows.

    Win+E Win+V Ctrl+Shift+Esc

  • Tuned for gaming

    Native Linux games, and Windows games through Proton with GE-Proton as the default. Performance will be measured against Windows on the same PC, and the results published.

  • Ready for development

    Code editors such as VS Code, AI coding tools and containers for your toolchains, with a proper terminal whenever you want one.

  • No terminal needed

    Installing apps, updating, changing settings and running games all work without typing a command, and Windows programs open with a double-click.

  • Updates you can trust

    Updates download in the background and apply when you restart. If something goes wrong, go back to the previous version in one click, or pick it from the boot menu.

  • Free, open and private

    Free to download and use, with its code open under the GPL. OrielOS collects nothing about you or your PC, and this website sets no cookies and runs no trackers.

Where it stands

OrielOS is in early development. Here’s what’s done, what’s being built now and what comes after, all the way to version 1.

  1. Done

    The foundations

    A Fedora system image with the KDE Plasma desktop, built and tested automatically in virtual machines with Secure Boot on, for every change.

    • A centred taskbar, Start, snap layouts, and OrielOS’s own look, sounds and sign-in screen
    • One Settings app, the Store with apps from Flathub, and Firefox
    • Signed updates on restart, with a way back to the previous version
  2. Done · 27 October 2026

    The first installer

    v0.0.7, the first stable release, with an installer for a USB stick. It installs on a whole drive or next to Windows.

    • Verified on real hardware: a laptop with an NVIDIA GeForce RTX 4050 Laptop GPU
    • The NVIDIA driver with Secure Boot on, Wi-Fi, Bluetooth, sound, the Store and Steam, and a real update
  3. Now

    Games and Windows programs

    Making games and Windows programs work without a terminal, tested on real hardware.

    • Run this app: open a Windows program with a double-click (in testing)
    • GE-Proton as Steam’s default for Windows games (in testing)
    • Game Settings, with per-game options
    • Will it run?, to check a game before you buy it
    • An FPS overlay and a Gaming page in Settings
  4. Next

    Desktop PCs and benchmarks

    Checking OrielOS on the desktop PCs it’s made for, and measuring it honestly.

    • Development tools: code editors, containers and a terminal, ready to use
    • Installs on desktop PCs with NVIDIA RTX graphics
    • Benchmarks against Windows on the same PC, published with the method
    • A real-hardware checklist before every stable release
  5. Then

    Version 1

    Ready for people switching from Windows to use every day.

    • Performance targets every version must meet
    • A privacy statement, and guides for every everyday task
    • What’s new in each update, shown before you restart
  6. After version 1

    More hardware, more languages

    Taking OrielOS beyond NVIDIA desktops.

    • AMD Radeon and Intel Arc graphics
    • Translations of OrielOS’s own parts
    • Perhaps a console-style gaming mode, and handhelds

Known limitations

  • Some online games won’t run. Games whose publishers block Linux in their anti-cheat, such as Valorant, League of Legends, Call of Duty and Battlefield 6, can’t be played on any Linux system. OrielOS starts in a way that meets Easy Anti-Cheat’s Linux requirements, so games that allow Linux can run. A way to check whether a game works before you buy it is planned.
  • No hibernation. The secure boot settings that anti-cheat needs rule it out. Sleep works as normal.
  • No Microsoft 365 or Adobe apps. They have no Linux versions. Use their web versions or Linux alternatives.
  • Not affiliated with Microsoft. OrielOS follows layouts and habits people know from Windows, but uses none of Microsoft’s logos, fonts, icons, sounds or wallpapers.
