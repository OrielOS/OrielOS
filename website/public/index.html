Welcome to OrielOS

A familiar desktop, tuned for gaming and development

OrielOS is a free and open-source Linux desktop for PCs with NVIDIA RTX graphics. Coming from Windows? The taskbar, Start menu, keyboard shortcuts and Settings are where you expect them.

Why OrielOS

  • Familiar from the first boot

    A centred taskbar, a Start menu with search and pinned apps, a Settings app organised by task, and the keyboard shortcuts you know from Windows.

    Win+E Win+V Ctrl+Shift+Esc

  • Tuned for gaming

    Native Linux games, and Windows games through Proton with GE-Proton as the default. Performance is measured against Windows on the same PC, and the results are published.

  • Ready for development

    Code editors such as VS Code, AI coding tools and containers for your toolchains, with a proper terminal whenever you want one.

  • No terminal needed

    Installing apps, updating, changing settings and running games all work without typing a command, and Windows programs open with a double-click.

  • Updates you can trust

    Updates download in the background and apply when you restart. If something goes wrong, go back to the previous version in one click, or pick it from the boot menu.

  • Free, open and private

    Free to download and use, with its code open under the GPL. OrielOS collects nothing about you or your PC, and this website sets no cookies and runs no trackers.

Already working in development builds

  • A Fedora system image with NVIDIA’s driver, signed for Secure Boot
  • The KDE Plasma desktop with a centred taskbar and OrielOS’s own look
  • Windows keyboard shortcuts such as Win+E, Win+R and Ctrl+Shift+Esc
  • The Store, with apps from Flathub, and Firefox
  • Updates on restart, with a way back to the previous version
  • Boot settings that meet Easy Anti-Cheat’s Linux requirements

Known limitations

  • Some online games won’t run. Games whose publishers block Linux in their anti-cheat, such as Valorant, League of Legends, Call of Duty and Battlefield 6, can’t be played on any Linux system. OrielOS shows which games work and which are blocked.
  • No hibernation. The secure boot settings that anti-cheat needs rule it out. Sleep works as normal.
  • No Microsoft 365 or Adobe apps. They have no Linux versions. Use their web versions or Linux alternatives.
  • Not affiliated with Microsoft. OrielOS follows layouts and habits people know from Windows, but uses none of Microsoft’s logos, fonts, icons, sounds or wallpapers.
