# The OrielOS desktop: KDE Plasma on Wayland, the system tools that stand in for Windows'
# built-in ones, and the services a desktop needs. Read by image/build/20-desktop.sh, which
# installs these packages without weak dependencies, so everything the desktop relies on is
# listed here explicitly. One package per line; text after # is a comment.
#
# Left out on purpose: apps that Flathub provides (Kate, Okular, Gwenview, Elisa, KMail,
# games, office apps, browsers), Discover's PackageKit and rpm-ostree backends (the OS is
# not changed package by package), Plasma's X11 session, Plasma's welcome app and Fedora's
# crash-reporting tools.

# Firmware for Wi-Fi and Bluetooth cards, so any common card works from the first boot: the
# drivers are in the kernel, but most cards also need a firmware file from these packages.
# linux-firmware (from the base image) recommends only some of them, and weak dependencies are
# off, so each is listed: Intel Wi-Fi from the oldest cards to Wi-Fi 7, Intel Bluetooth,
# Qualcomm/Atheros Wi-Fi and Bluetooth (atheros-firmware, which includes ath11k, ath12k and qca),
# MediaTek, Realtek, Broadcom, NXP/Marvell, TI and old USB sticks (ZyDAS, Atmel). Also Intel's
# laptop camera sensors and TV tuners. qcom-firmware is left out: it is for Arm Snapdragon
# devices. 20-desktop.sh checks a firmware file for each chip family.
linux-firmware
iwlwifi-mvm-firmware
iwlwifi-mld-firmware
iwlwifi-dvm-firmware
iwlegacy-firmware
iwlbluetooth-firmware
atheros-firmware
mediatek-firmware
mt7xxx-firmware
realtek-firmware
brcmfmac-firmware
nxpwireless-firmware
libertas-firmware
tiwilink-firmware
zd1211-firmware
atmel-firmware
intel-vsc-firmware
dvb-firmware
