# apps

OrielOS's own apps, written in C++ with Qt 6, QML and Kirigami and built with CMake.

Will contain:

- Settings.
- Game Settings.
- Run this app, which runs Windows `.exe` and `.msi` programs through Proton.
- The update service and notifier.
