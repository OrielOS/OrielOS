# Support

- **Questions:** ask in the [Q&A](https://github.com/ncjsvr/OrielOS/discussions/categories/q-a) category of GitHub Discussions.
- **Ideas, feedback and anything else:** post in the [General](https://github.com/ncjsvr/OrielOS/discussions/categories/general) category.
- **Live chat and quick help:** [the official OrielOS Discord server](https://discord.gg/RnpZYaKbHA). It's the only official OrielOS Discord server; any other server using the name isn't run by the project. Anything that needs a record, such as a bug, a question others will look for or a decision, still belongs on GitHub.
- **News and releases:** follow [Announcements](https://github.com/ncjsvr/OrielOS/discussions/categories/announcements), which the maintainer posts.
- **Bugs, game compatibility, hardware support and feature requests:** open an issue using one of the [issue forms](https://github.com/ncjsvr/OrielOS/issues/new/choose).
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not report them publicly.

OrielOS is a volunteer project. There is no paid support, and replies are best effort.
